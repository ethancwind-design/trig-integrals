# Trig Quest

One project: a slide-deck game (identities, integrals, MATH 1400 exam prep) plus a searchable library.
Open `index.html` (needs internet once for MathJax and fonts; add `?fast` to skip the boot screen).

Everything is presented like *Trig Substitution in Motion*: a 16:9 graph-paper stage, eyebrow + title, phase pills,
caption bar, and a Back / jump / "n of N" / Next / Full screen toolbar.

| File | What it is |
|---|---|
| `index.html`, `quest.js`, `quest.css` | The game: boot screen, main menu, Story Mode (7 story lines, missions, bosses), Daily Run, Blitz, Survival. Progress is saved in localStorage (`trigquest.v1`). |
| `codex.html`, `app.js`, `style.css` | Free-roam library: every formula, search, study mode that hides answers. |
| `motion.html` | The animated trig-substitution lesson (cutscene), listed inside Practice Lessons in Motion. |
| `lesson/` | 102 animated Motion-style lessons, one per prep-quiz / practice question (`index.html` lists the six decks and the Trig Substitution cutscene; `quiz-4-practice.html` is the Fall 26 Quiz 4 deck: `deck-q4a`-`q4d` + `deck-q4z`, built with `kit-q4.js` and `volGen`). Source decks `deck-*.js` + generators `kit*.js`; verify with `node lesson/check.js` and `__lesson.qa()` in the browser; regenerate shells with `node lesson/mkshell.js`. |
| `data.js` | Generated by `build/build.py`: the verified integral/identity problems. Do not edit. |
| `refdata.js`, `refconv.js` | Generated cheat sheets (identities, exact values, calculus formulas) and the converter that shapes them like `data.js`. |
| `img/q/`, `shots.js`, `shotui.js` | Crops of the source PDF (77 questions: `<key>.webp`, plus `<key>-q.webp` stems without answer options for the Canvas quizzes). `shots.js` is generated by `build/shots.py`; `shotui.js` finds a problem's crop from its `src` label and renders the bordered "Original question" box (click to enlarge). Shown in the game (side panel), the codex cards, and the lessons ("Original question" button). |
| `buddy.js` | The choose-your-character dancer, loaded on every page. First visit shows a picker; the pick is saved in localStorage (`trigquest.buddy`) and the character dances in the bottom-right corner (the small ⇄ button re-opens the picker). Both are Sketchfab embeds, CC BY 4.0: "Stickman Samba Dancing" by adu2763 and "Rickoshea old" by MAXIDOG_P3D (that one has no animation of its own, so the page spins and bounces it). Needs internet. |
| `build/` | Sources and verifiers. `shots.py` re-crops the PDF (`python3 build/shots.py`; needs poppler + Pillow + numpy). `s_recitation.py` is the Recitation section (Worksheet 4, verified like the rest); `recitation.py` turns the worksheet photos (HEIC) and handwritten solutions PDF into `rec-N` / `recsol-N` crops. |

## Add or fix content

    python3 -m venv .venv && .venv/bin/pip install mpmath
    # integrals / problems: edit build/s_<section>.py (new ones live in s_extra.py)
    .venv/bin/python build/build.py        # differentiates every antiderivative, integrates every definite value (30 digits)
    # cheat sheets: edit build/ref_src.json, then
    .venv/bin/python build/ref_build.py    # parses every plain-equation row and checks it numerically, writes refdata.js

Story lines and chapters are declared in `quest.js` (`STORY`); they pull problems from the sections above.
